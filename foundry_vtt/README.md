# Foundry VTT

Run your own Foundry Virtual Tabletop server inside Home Assistant.

- Needs a paid Foundry license and your foundryvtt.com login.
- Web interface on port 30000.
- Works behind a reverse proxy such as Nginx Proxy Manager.
- Worlds, modules and settings are kept in the add-on data folder.

See the Documentation tab for setup steps and every option.
